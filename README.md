# Student Performance Analysis Using MySQL

## 📌 Project Overview

This project analyzes student academic performance using MySQL. It explores students' mathematics, reading, and writing scores to identify patterns and compare academic performance across different student groups.

## 🎯 Objectives

- Analyze student performance across three subjects.
- Compare average scores by gender.
- Examine the distribution of test preparation course participation.
- Explore relationships between parental education and academic performance.
- Identify students with high, low, and varying subject scores.

## 📊 Dataset

The dataset contains student information, including:
- Gender
- Race/Ethnicity
- Parental Level of Education
- Lunch Type
- Test Preparation Course
- Mathematics Score
- Reading Score
- Writing Score

**Source:** Kaggle

## 🔍 SQL Analysis

The project uses MySQL queries to perform:

- Data filtering using `WHERE`
- Sorting using `ORDER BY`
- Grouping using `GROUP BY`
- Conditional filtering using `HAVING`
- Aggregate calculations using `AVG()`, `MAX()`, `MIN()`, and `COUNT()`
- Range filtering using `BETWEEN`
- Multiple-condition filtering using logical operators
- Subqueries to compare scores against overall averages

## 💡 Key Insights

- Compared average mathematics, reading, and writing scores by gender.
- Examined student participation in test preparation courses.
- Identified the highest and lowest scores in each subject.
- Analyzed students who performed well across multiple subjects.
- Explored mathematics performance across parental education groups.
- Compared individual mathematics scores with the overall average.
